Pronòstics amb model estadístic

La quiniela proposa un únic signe (1, X o 2): el de probabilitat més alta segons el model estadístic. També mostra les probabilitats dels tres resultats, la confiança i la mostra utilitzada. Les baixes i sancions només modifiquen el càlcul quan estan verificades i incorporades a les dades.
